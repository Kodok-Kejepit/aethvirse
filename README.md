# AETHVIRSE: Unseal the Codex — Unity

Third-person 3D action RPG, migrated from the Godot prototype (`../aethvirse`).

- Engine: Unity 6000.3.29f1 (Unity 6.3 LTS)
- Boot scene: `Assets/Scenes/Boot.unity` (`AETHVIRSE > Setup Boot Scene` recreates it and the build settings)
- CI: GameCI (`.github/workflows/build.yml`) builds Windows and Android on every push to `main`
